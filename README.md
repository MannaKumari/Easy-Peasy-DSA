DSA Algorithm Visualizer

DSA Algorithm Visualizer is a web-based application designed to demonstrate the working of fundamental Data Structures and Algorithms through interactive visual representations. The application provides step-by-step execution of algorithms to enhance conceptual clarity and problem-solving skills.

Overview

This project aims to simplify the understanding of complex algorithms by presenting them in a visual and interactive format. Users can generate random data and observe how different algorithms process the data internally.

Features

Visualization of multiple sorting algorithms

Graph traversal using DFS and BFS

Shortest path finding using Dijkstra’s Algorithm

Minimum Spanning Tree using Kruskal’s Algorithm

Random data and graph generation

Step-by-step animation for better understanding

Simple and user-friendly interface

Algorithms Implemented
Sorting Algorithms

Bubble Sort

Selection Sort

Insertion Sort

Graph Algorithms

Breadth First Search (BFS)

Depth First Search (DFS)

Pathfinding

Dijkstra’s Shortest Path Algorithm

Minimum Spanning Tree

Kruskal’s Algorithm
